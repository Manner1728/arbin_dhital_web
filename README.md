# Arbin Dhital Website

Premium GitHub-ready static website for **arbindhital.com.np**.

## Included in this updated version
- Corrected branding: **Arbin Dhital** / **अर्बिन धिताल**
- Nepali-first interface with English language switch
- Light mode and dark mode
- Strong animations: preloader, particles, glowing effects, scroll reveal, tilt hover and floating visual elements
- Outstanding recently generated images integrated into the design
- Featured poem section with copy button and reading mode
- Future-ready sections for poems, literature, blogs, videos and vlogs
- Local flute-style melody audio
- Multiple local devotional videos for GitHub Pages
- Fully responsive layout for desktop and mobile

## Deployment
1. Create a GitHub repository in your own GitHub account.
2. Upload all files from this folder to the repository root.
3. Commit and push.
4. Enable **GitHub Pages** from the main branch root.
5. Later, connect Cloudflare / DNS to the GitHub Pages site.

## Main editable files
- `index.html`
- `assets/css/styles.css`
- `assets/js/app.js`
- `assets/images/`
- `assets/media/`

## Notes
- The website does **not** use the original photo with its unchanged background.
- You can later replace any local audio/video with your own upgraded media while keeping the same paths if desired.
