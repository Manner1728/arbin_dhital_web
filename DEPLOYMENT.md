# Deployment checklist

- [ ] Extract the ZIP
- [ ] Confirm `index.html` is at repository root
- [ ] Upload all files and folders to the `main` branch
- [ ] Enable GitHub Pages from `main` and `/(root)`
- [ ] Test the GitHub Pages URL
- [ ] Replace the placeholder contact email
- [ ] Add real social links when available
- [ ] Configure `arbindhital.com.np` in GitHub Pages
- [ ] Add the required DNS records in Cloudflare
- [ ] Enable HTTPS enforcement in GitHub Pages after certificate issuance
- [ ] Verify both desktop and mobile views
